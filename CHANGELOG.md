# Changelog

## 0.2.0 — 2026-11-18

- Compact 304 px popover with sans-serif typography, smaller padding, and tighter
  vertical spacing. Manrope is bundled locally; the owner-approved softened neutral/tangerine palette
  is applied in light and dark mode.
- Compact Radix Select/Tooltip controls, persistent System/Light/Dark appearance,
  and keyboard-shortcut chips.
- Saved external search-engine choices: Google, Bing, DuckDuckGo, Brave Search,
  Ecosia, and custom HTTPS templates using `{query}`.
- Tray Settings entry, quick engine selection, and clipboard-fallback toggle,
  synchronized with the settings panel and preserved across restarts.
- Preference migration, URL validation/encoding, and isolated native settings tests.

## 0.1.0 — 2026-11-18

- Initial online Windows prototype, word-meaning navigation, pronunciation links,
  source attribution, tray lifecycle, shortcut, and explicit clipboard lookup.
- Original WordPeek identity, contributor/agent conventions, CI, and protected main.
