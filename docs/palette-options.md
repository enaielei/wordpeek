# Approved brand direction

The owner chose **Manrope + Radix + Soft Tangerine** on 2026-11-18.
Both modes use softened neutral gray backgrounds and text. Tangerine is reserved
for pronunciation, keyboard focus, the mark, and small highlights. Earlier blue,
violet, terracotta, amber, and more saturated orange proposals were not selected.

Canonical values: src/brand/tokens.css. Full rules: docs/brand-guidelines.md.
