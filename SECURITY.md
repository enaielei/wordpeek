# Security policy

This is an early prototype; only the latest main-branch version receives fixes.
Do not use public issues for secrets or exploitable vulnerability details.

Use GitHub's **Report a vulnerability** button if private vulnerability reporting is
enabled on this repository. If unavailable, contact the maintainer privately through
the contact information they choose to publish on their GitHub profile. Do not post
sensitive details publicly while requesting a reporting channel.

Include affected version, reproduction, impact, and a minimal non-sensitive example.
Do not include private selected text or credentials. Ordinary bugs belong in issues.
